# AI Workforce Intelligence Dashboard

Backend foundation completed.

## Stack

- Next.js 16
- Tailwind v4
- Supabase (Postgres + Auth)
- Recharts
- TanStack Table

## Setup

1. Create Supabase project
2. Run `supabase/seed.sql`
3. Create manager + employees in Auth
4. Run team/manager assignment section

More features coming in V2.
